# 📚 Учебные заметки

## 📦 Переменные

Переменная — это имя, которое используется для хранения значения в программе.
Переменная хранит данные, которые можно использовать и изменять во время работы программы.
Она создаётся присваиванием: name = "MAX", age = 25.
Тип значения определяется автоматически: `int`, `float`, `str`, `bool`, True/False и другие.
Значение переменной можно изменить: `age = 20`, затем `age = 21`.
Используй понятные имена: user_name, total_price, age.
Одна переменная может использоваться в вычислениях и передаваться другим функциям.
Можно создать несколько переменных в одной строке.

## 📋 Списки (Lists)

Список (list) — структура данных, которая позволяет хранить несколько элементов в одной переменной. Списки записываются в квадратных скобках [], а элементы разделяются запятыми.
Индексация начинается с 0.
Первый элемент имеет индекс 0, второй 1..
Отрицательные индексы позволяют обращаться к элементам с конца списка.
Индекс -1 обозначает последний элемент.
Элемент списка можно заменить, обратившись к нему по индексу и присвоив новое значение.

append() — добавляет элемент в конец списка.

insert() — добавляет элемент на указанную позицию. Остальные элементы сдвигаются.

del — удаляет элемент по индексу.

pop() — удаляет элемент по индексу и возвращает его значение. Без аргументов удаляет последний элемент.

remove() — удаляет первое совпадение указанного значения.

clear() — удаляет все элементы списка.
